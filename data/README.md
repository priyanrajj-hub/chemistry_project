# Data Source Information

This directory is intended for raw data.
For this project, we are simulating the **NASA PCoE Li-ion Aging Dataset** due to its large size.
The simulation replicates capacity fade over cycles.
A cached subset of this simulated data will appear in `sample/nasa_battery_sample.csv` when `nasa_dataset_loader.py` is executed.

See: [NASA Prognostics Data Repository](https://ti.arc.nasa.gov/tech/dash/groups/pcoe/prognostic-data-repository/)
